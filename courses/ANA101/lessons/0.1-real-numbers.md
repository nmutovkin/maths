After this lesson you will be able to:

- describe the number systems ℕ, ℤ, ℚ, ℝ and prove that $\sqrt 2$ is irrational;
- manipulate inequalities correctly, including multiplying by negative numbers;
- solve polynomial, rational and absolute-value inequalities;

## Notes

### Number systems

We use the following sets of numbers, each contained in the next:

$$\mathbb N \subset \mathbb Z \subset \mathbb Q \subset \mathbb R.$$

- $\mathbb N = \{1, 2, 3, \dots\}$, the **natural numbers**.
- $\mathbb Z = \{\dots, -2, -1, 0, 1, 2, \dots\}$, the **integers**.
- $\mathbb Q = \{p/q : p, q \in \mathbb Z,\ q \ne 0\}$, the **rational numbers**.
- $\mathbb R$, the **real numbers**: all points of the number line.

Every rational number is real, but not every real number is rational. Real
numbers that are not rational are called **irrational**.

**Theorem 1.** $\sqrt 2$ is irrational.

*Proof.* Suppose, for contradiction, that $\sqrt 2 = p/q$ with $p, q \in \mathbb Z$,
$q \neq 0$. By cancelling common factors we may assume $p$ and $q$ have no
common factor. Squaring gives $p^2 = 2q^2$, so $p^2$ is even. Since the square
of an odd number is odd, $p$ is even: $p = 2k$ for some integer $k$. Then
$4k^2 = 2q^2$, so $q^2 = 2k^2$ is even and therefore $q$ is even. Now $p$ and
$q$ are both even, contradicting the assumption that they have no common
factor. ∎

So the rational numbers have "gaps": there is no rational number whose square
is 2, although there are rationals whose squares are as close to 2 as we like.
The real numbers fill these gaps. This property is called **completeness**,
and it is stated precisely as follows: *every non-empty set of real numbers
that is bounded above has a least upper bound.* Completeness is what makes
calculus work. It is behind the intermediate value theorem (Lesson 1.6) and
the extreme value theorem (Lesson 3.1), and it is studied in detail in ANA202.

### Inequalities

The real numbers are **ordered**: for any $a, b \in \mathbb R$, exactly one of
$a < b$, $a = b$, $a > b$ holds. We write $a \le b$ for "$a < b$ or $a = b$".
Inequalities obey the following rules, for all real $a, b, c$:

1. If $a < b$ and $b < c$, then $a < c$.
2. If $a < b$, then $a + c < b + c$.
3. If $a < b$ and $c > 0$, then $ac < bc$.
4. If $a < b$ and $c < 0$, then $ac > bc$. *Multiplying by a negative number
   reverses an inequality.*
5. If $0 < a < b$, then $1/a > 1/b$.
6. If $a \le b$ and $c \le d$, then $a + c \le b + d$.
7. For every real $a$, $a^2 \ge 0$, with equality only when $a = 0$.

The same rules hold with $\le$ in place of $<$.

**Intervals.** For $a < b$ we use the following notation:

| Notation | Set | Notation | Set |
|---|---|---|---|
| $(a, b)$ | $\{x : a < x < b\}$ | $(a, \infty)$ | $\{x : x > a\}$ |
| $[a, b]$ | $\{x : a \le x \le b\}$ | $[a, \infty)$ | $\{x : x \ge a\}$ |
| $[a, b)$ | $\{x : a \le x < b\}$ | $(-\infty, b)$ | $\{x : x < b\}$ |
| $(a, b]$ | $\{x : a < x \le b\}$ | $(-\infty, b]$ | $\{x : x \le b\}$ |

A round bracket means the endpoint is excluded; a square bracket means it is
included. The symbol $\infty$ is not a number, so it always gets a round
bracket. $(-\infty, \infty)$ is all of $\mathbb R$.

### Absolute value

**Definition 2.** The **absolute value** of a real number $x$ is

$$|x| = \begin{cases} x & \text{if } x \ge 0, \\ -x & \text{if } x < 0. \end{cases}$$

For example $|3| = 3$, $|-3| = 3$, $|0| = 0$. Geometrically, $|x|$ is the
distance from $x$ to $0$ on the number line, and $|x - a|$ is the **distance
between $x$ and $a$**. This distance interpretation is the main reason absolute
values matter in calculus: "$x$ is close to $a$" will mean "$|x - a|$ is small".

Basic properties, for all real $x, y$:

- $|x| \ge 0$, and $|x| = 0$ only when $x = 0$;
- $|-x| = |x|$ and $-|x| \le x \le |x|$;
- $|xy| = |x|\,|y|$, and $|x / y| = |x| / |y|$ if $y \neq 0$;
- $\sqrt{x^2} = |x|$. (Not $x$: for example $\sqrt{(-3)^2} = 3$.)

**Theorem 3.** Let $c > 0$. Then

- $|x| < c$ if and only if $-c < x < c$;
- $|x| > c$ if and only if $x > c$ or $x < -c$.

The same holds with $\le$ and $\ge$ in place of $<$ and $>$.

*Proof.* If $x \ge 0$, then $|x| = x$ and $x \ge 0 > -c$, so $|x| < c$ is
equivalent to $-c < x < c$. If $x < 0$, then $|x| = -x$, and $-x < c$ means
$x > -c$; also $x < 0 < c$. So again $|x| < c$ is equivalent to $-c < x < c$.
The second statement is the negation of the first (with $\le$), so it follows. ∎

In terms of distance: $|x - a| < c$ says that $x$ is within distance $c$ of $a$,
that is, $x \in (a - c, a + c)$.

**Theorem 4 (Triangle inequality).** For all real $a$ and $b$,

$$|a + b| \le |a| + |b|.$$

*Proof.* We have $-|a| \le a \le |a|$ and $-|b| \le b \le |b|$. Adding these
(rule 6) gives $-(|a| + |b|) \le a + b \le |a| + |b|$. By Theorem 3 with
$c = |a| + |b|$, this says exactly $|a + b| \le |a| + |b|$. (If $c = 0$, then
$a = b = 0$ and the inequality is trivial.) ∎

The name comes from the analogous fact for vectors: one side of a triangle is
no longer than the other two together. A useful consequence, proved in
Exercise B3, is the **reverse triangle inequality**

$$\big|\,|a| - |b|\,\big| \le |a - b|.$$

### Solving inequalities

To solve an inequality means to find the set of all $x$ for which it holds.

**Polynomial and rational inequalities.** Move everything to one side so the
inequality compares an expression with 0, factor it, and use a **sign chart**:
a product or quotient of factors changes sign only where some factor is zero
(or undefined). Between these points its sign is constant, so one test point
per interval is enough.

**Absolute-value inequalities.** Use Theorem 3 to remove the absolute value.
If several absolute values appear, split into cases according to the sign of
each expression inside.

## Worked examples

**Example 1.** Solve $\dfrac{x - 1}{x + 2} \le 0$.

*Solution.* The numerator is zero at $x = 1$; the denominator is zero at
$x = -2$, where the expression is undefined. These points split the line into
three intervals:

| Interval | $x - 1$ | $x + 2$ | $\frac{x-1}{x+2}$ |
|---|---|---|---|
| $x < -2$ | − | − | + |
| $-2 < x < 1$ | − | + | − |
| $x > 1$ | + | + | + |

The expression is negative on $(-2, 1)$ and equals 0 at $x = 1$. The point
$x = -2$ is excluded. **Answer:** $(-2, 1]$.

**Example 2.** Solve $|2x - 3| < 5$.

*Solution.* By Theorem 3, $-5 < 2x - 3 < 5$. Add 3: $-2 < 2x < 8$. Divide by 2
(positive, so no reversal): $-1 < x < 4$. **Answer:** $(-1, 4)$.

**Example 3.** Solve $|x - 1| + |x + 2| \ge 5$.

*Solution.* The expressions inside change sign at $x = 1$ and $x = -2$, so we
consider three cases.

- $x \ge 1$: both are non-negative, and the inequality is
  $(x - 1) + (x + 2) \ge 5$, i.e. $2x + 1 \ge 5$, so $x \ge 2$.
- $-2 \le x < 1$: it becomes $(1 - x) + (x + 2) \ge 5$, i.e. $3 \ge 5$. False,
  so there are no solutions in this case.
- $x < -2$: it becomes $(1 - x) - (x + 2) \ge 5$, i.e. $-2x - 1 \ge 5$, so
  $x \le -3$.

**Answer:** $(-\infty, -3] \cup [2, \infty)$.

*Check with distances.* $|x - 1| + |x + 2|$ is the sum of the distances from
$x$ to $1$ and to $-2$. For $x$ between them this sum is always 3, the distance
between $-2$ and $1$; outside, it grows by 2 for every unit we move away. It
reaches 5 one unit beyond each end: at $x = 2$ and $x = -3$.

**Example 4.** Show that if $|x - 2| < 1$, then $|x^2 - 4| < 5$.

*Solution.* Factor: $|x^2 - 4| = |x - 2|\,|x + 2|$. We know $|x - 2| < 1$, so
we need a bound for $|x + 2|$. Write $x + 2 = (x - 2) + 4$ and use the triangle
inequality:

$$|x + 2| \le |x - 2| + 4 < 1 + 4 = 5.$$

Therefore $|x^2 - 4| = |x - 2|\,|x + 2| < 1 \cdot 5 = 5$.

This kind of estimate (control one factor directly, bound the other with the
triangle inequality) is exactly what is needed to prove limits in Lesson 1.2.

## Common mistakes

- **Multiplying by an expression of unknown sign.** To solve
  $\frac{x-1}{x+2} \le 0$ you cannot just multiply by $x + 2$, since it is
  negative for some $x$ and positive for others. Use a sign chart instead.
- **Writing $\sqrt{x^2} = x$.** It is $|x|$.
- **Writing $|a + b| = |a| + |b|$.** This fails when $a$ and $b$ have opposite
  signs: $|3 + (-5)| = 2$, but $|3| + |-5| = 8$. Only the inequality holds in
  general.
- **Squaring both sides of an inequality carelessly.** For $a, b \ge 0$,
  $a < b$ is equivalent to $a^2 < b^2$. Without the sign condition this fails:
  $-3 < 2$ but $9 > 4$.
- **Forgetting excluded points.** Points where an expression is undefined
  (like $x = -2$ in Example 1) are never part of the solution.

## Exercises

### A. Routine

**A1.** Write each set in interval notation:
(a) $\{x : -2 < x \le 3\}$; (b) $\{x : x \ge 5\}$; (c) $\{x : |x| < 4\}$.

<details>
<summary>Solution</summary>

(a) $(-2, 3]$. (b) $[5, \infty)$. (c) By Theorem 3, $|x| < 4$ means
$-4 < x < 4$, so the set is $(-4, 4)$.

</details>

**A2.** Solve $|x + 4| \le 2$.

<details>
<summary>Solution</summary>

$-2 \le x + 4 \le 2$, so $-6 \le x \le -2$. **Answer:** $[-6, -2]$.
These are the points within distance 2 of $-4$.

</details>

**A3.** Solve $|3 - x| > 1$.

<details>
<summary>Solution</summary>

By Theorem 3, $3 - x > 1$ or $3 - x < -1$, that is, $x < 2$ or $x > 4$.
**Answer:** $(-\infty, 2) \cup (4, \infty)$.

</details>

**A4.** Solve $x^2 - x - 6 < 0$.

<details>
<summary>Solution</summary>

Factor: $(x - 3)(x + 2) < 0$. The product is negative exactly when the factors
have opposite signs, which happens for $-2 < x < 3$.
**Answer:** $(-2, 3)$.

</details>

### B. Standard

**B1.** Solve $\dfrac{x + 1}{x - 3} \ge 2$.

<details>
<summary>Solution</summary>

Do not multiply by $x - 3$, whose sign is unknown. Instead subtract 2:

$$\frac{x + 1}{x - 3} - 2 = \frac{x + 1 - 2(x - 3)}{x - 3} = \frac{7 - x}{x - 3} \ge 0.$$

Sign chart, with critical points $3$ and $7$:

| Interval | $7 - x$ | $x - 3$ | quotient |
|---|---|---|---|
| $x < 3$ | + | − | − |
| $3 < x < 7$ | + | + | + |
| $x > 7$ | − | + | − |

The quotient is positive on $(3, 7)$, zero at $x = 7$, and undefined at $x = 3$.
**Answer:** $(3, 7]$.

</details>

**B2.** Solve $|x - 1| < |x + 3|$, and interpret the answer in terms of
distances.

<details>
<summary>Solution</summary>

Both sides are non-negative, so the inequality is equivalent to the one
obtained by squaring:

$$(x - 1)^2 < (x + 3)^2 \iff x^2 - 2x + 1 < x^2 + 6x + 9 \iff -8 < 8x \iff x > -1.$$

**Answer:** $(-1, \infty)$. Interpretation: these are the points closer to $1$
than to $-3$. The point $-1$ is halfway between them.

</details>

**B3.** Prove the reverse triangle inequality: for all real $a, b$,
$\big|\,|a| - |b|\,\big| \le |a - b|$.

<details>
<summary>Solution</summary>

Write $a = (a - b) + b$. By the triangle inequality,
$|a| \le |a - b| + |b|$, so

$$|a| - |b| \le |a - b|.$$

Swapping the roles of $a$ and $b$ gives $|b| - |a| \le |b - a| = |a - b|$, so

$$-|a - b| \le |a| - |b|.$$

Together, $-|a - b| \le |a| - |b| \le |a - b|$, which by Theorem 3 means
$\big|\,|a| - |b|\,\big| \le |a - b|$. ∎

</details>

**B4.** Show that if $|x - 3| < 1$, then $\left|\dfrac1x - \dfrac13\right| < \dfrac16$.

<details>
<summary>Solution</summary>

First combine the fractions:

$$\left|\frac1x - \frac13\right| = \left|\frac{3 - x}{3x}\right| = \frac{|x - 3|}{3|x|}.$$

From $|x - 3| < 1$ we get $2 < x < 4$, so $|x| = x > 2$ and $3|x| > 6$. Hence
the numerator is less than 1 and the denominator is greater than 6, so

$$\frac{|x - 3|}{3|x|} < \frac{1}{6}.$$

</details>

**B5.** Prove that for all $a, b \ge 0$,
$$\frac{a + b}{2} \ge \sqrt{ab},$$
with equality if and only if $a = b$. (The arithmetic mean is at least the
geometric mean.)

<details>
<summary>Solution</summary>

Since $a, b \ge 0$, the square roots $\sqrt a$ and $\sqrt b$ exist, and by
rule 7,

$$0 \le \left(\sqrt a - \sqrt b\right)^2 = a - 2\sqrt{ab} + b.$$

Rearranging gives $a + b \ge 2\sqrt{ab}$; divide by 2. Equality holds exactly
when $\sqrt a - \sqrt b = 0$, i.e. $\sqrt a = \sqrt b$, i.e. $a = b$. ∎

</details>

### C. Challenge

**C1.** Prove that $\sqrt 2 + \sqrt 3$ is irrational.

<details>
<summary>Solution</summary>

*Step 1: $\sqrt 6$ is irrational.* Suppose $\sqrt 6 = p/q$ with $p, q$ integers
having no common factor. Then $p^2 = 6q^2$ is even, so $p$ is even, say
$p = 2k$. Then $4k^2 = 6q^2$, so $2k^2 = 3q^2$. Thus $3q^2$ is even; since 3 is
odd, $q^2$ is even, so $q$ is even. Both $p$ and $q$ are even, a contradiction.

*Step 2.* Suppose $\sqrt 2 + \sqrt 3 = r$ with $r$ rational. Squaring,

$$r^2 = 2 + 2\sqrt 6 + 3 = 5 + 2\sqrt 6, \qquad\text{so}\qquad \sqrt 6 = \frac{r^2 - 5}{2}.$$

The right-hand side is rational, since sums, products and quotients of
rationals are rational. This contradicts Step 1. ∎

</details>

**C2.** Prove that $|x - 1| + |x - 3| \ge 2$ for every real $x$, and find all
$x$ for which equality holds.

<details>
<summary>Solution</summary>

Since $|x - 3| = |3 - x|$, the triangle inequality gives

$$|x - 1| + |3 - x| \ge |(x - 1) + (3 - x)| = |2| = 2.$$

For equality: both sides of $|a + b| \le |a| + |b|$ are non-negative, so they
are equal exactly when their squares are. Since
$|a + b|^2 = a^2 + 2ab + b^2$ and $(|a| + |b|)^2 = a^2 + 2|ab| + b^2$, equality
holds exactly when $ab = |ab|$, that is, when $ab \ge 0$. Here $a = x - 1$ and $b = 3 - x$, and $(x - 1)(3 - x) \ge 0$ exactly when
$1 \le x \le 3$.

**Answer:** equality holds for $x \in [1, 3]$. In terms of distances: the sum of
the distances from $x$ to $1$ and $3$ is smallest, equal to 2, for points
between them.

</details>

**C3.** Prove **Bernoulli's inequality**: for every real $x \ge -1$ and every
$n \in \mathbb N$,
$$(1 + x)^n \ge 1 + nx.$$

<details>
<summary>Solution</summary>

Induction on $n$. For $n = 1$ both sides equal $1 + x$.

Suppose $(1 + x)^n \ge 1 + nx$ for some $n$. Since $x \ge -1$, we have
$1 + x \ge 0$, so multiplying both sides by $1 + x$ keeps the direction of the
inequality (rule 3 if $1 + x > 0$; if $1 + x = 0$ both sides become 0):

$$(1 + x)^{n+1} \ge (1 + nx)(1 + x) = 1 + (n + 1)x + nx^2 \ge 1 + (n + 1)x,$$

because $nx^2 \ge 0$. This is the statement for $n + 1$, so by induction it
holds for all $n \in \mathbb N$. ∎

The condition $x \ge -1$ was used exactly once, to multiply by $1 + x$ safely.

</details>

## Summary

- $\mathbb N \subset \mathbb Z \subset \mathbb Q \subset \mathbb R$; $\sqrt 2$
  is irrational. The reals are **complete**: they have no gaps.
- Multiplying an inequality by a negative number reverses it.
- $|x - a|$ is the distance between $x$ and $a$. For $c > 0$:
  $|x - a| < c \iff a - c < x < a + c$.
- **Triangle inequality:** $|a + b| \le |a| + |b|$. **Reverse:**
  $\big|\,|a| - |b|\,\big| \le |a - b|$.
- Solve rational inequalities with a sign chart, and absolute-value
  inequalities with Theorem 3 or by splitting into cases.
